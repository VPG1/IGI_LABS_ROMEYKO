## Запуск Python

Нужен Python 3.10 или новее. Для задания 4 нужна библиотека Matplotlib.
Команды ниже выполняются из каталога с этим README.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
cd Task2
python3 main.py
```

В Windows используйте `python` вместо `python3`, а для активации окружения
в PowerShell — `.venv\Scripts\Activate.ps1`.

В меню 2А размер списка задается пользователем. Доступны ввод и генератор.
В меню 2Б укажите исходный файл UTF-8, файл результата `.txt` и строку пароля.
Программа допускает повторный запуск заданий без выхода из меню.

Воспроизводимый пример 2Б из каталога `Task2`:

```bash
python3 main.py --input input.txt --output results/result.txt --password C00l_Pass --verbose
```

Будут созданы `result.txt`, `result.json`, `result.zip` и `archive_info.json`.
Файл в ZIP проверяется по CRC; размер, сжатый размер, имя, дата и CRC выводятся
на экран. Исходный файл защищен от перезаписи результатом.

Правила анализа: словом считается непрерывная последовательность букв,
цифр и символов `_`. Для прописных слов используются только буквы латиницы
и кириллицы. Повторы сравниваются без учета регистра. Поиск начальной `l`
не учитывает регистр; при равной длине выбирается первое слово. Пароль
проверяется строго по учебному условию, включая только ASCII буквы, цифры
и `_`. Задание 2А использует `str.isdigit()` без регулярных выражений.

Предложения выделяются по `.`, `?`, `!`. Конечный фрагмент без знака считается
повествовательным, `?` имеет приоритет над `!`. Категория побудительных
определяется по `!`; это формальное правило, без грамматического анализа.
Сокращения и десятичные точки отдельно не распознаются. При расчете средней
длины предложения учитываются только символы слов. Смайлик должен содержать
целую последовательность одинаковых скобок; смешанные скобки не считаются.

Задание 4 из каталога `Task4`:

```bash
python3 main.py
python3 main.py --side 5 --color skyblue --label "Вариант 8" --output results/pentagon.png
```

Для работы без графического окна добавьте `--no-show`. Доступны PNG, PDF,
SVG; интерактивный режим показывает окно графика и сохраняет изображение.
Площадь при `a = 5`: `43.0119350147`.

Проверки из корневого каталога:

```bash
python3 -m unittest discover -s tests -v
```

## Docker

Сборка выполняется из каталога с этим README: контекст содержит `Task2` и `Task3`.

```bash
docker build -f Task3/Dockerfile -t kr1-variant8:1.0 .
docker run --rm -e TEXT="Вариант 8, 2026" kr1-variant8:1.0
docker run --rm kr1-variant8:1.0 --text "abc12345"
printf '%s\n' 'abc12345' | docker run --rm -i kr1-variant8:1.0
python3 Task3/demo_docker.py
```

Демонстрация создает объекты со случайным суффиксом, выполняет `build`,
`tag`, `run`, `start`, `stop`, `pause`, `unpause`, `restart`, `ps`, `logs`,
`images`, `network`, `volume`, `inspect` и удаляет свои временные объекты.
Команда Docker для томов называется `volume` в единственном числе.
Для проверки жизненного цикла используется отдельный долго работающий процесс;
основной контейнер 2А завершается сразу после вывода результата.

## Git

Команды скрипта рассчитаны на Bash в macOS/Linux или Git Bash в Windows.
Скрипт выполняет CLI команды Git и сохраняет реальный вывод до и после операций.
Настройки имени и учебного email применяются только к созданному репозиторию.

```bash
python3 Task1/git_lab.py --destination ./453501_ROMEIKO_8 --group 453501 --list-number 8
```

Числа выше приведены как пример запуска; замените их своими значениями.
Скрипт работает только с новым каталогом. Перед `revert`, `restore` и удалением
файлов создаются отдельные учебные изменения в этом каталоге.

Локальный `geometric_lib` подключен как подмодуль. В клоне из GitHub:

```bash
git submodule update --init --recursive
git branch -a
git switch IGI-KR1
```

Шесть предметных веток содержат свои папки. На ветке `main` хранится полная
структура. Переименование удаленного репозитория демонстрируется как смена
локального имени remote `origin` -> `coursework` -> `origin`, адрес GitHub тот же.

Репозиторий: https://github.com/VPG1/IGI_LABS_ROMEYKO
